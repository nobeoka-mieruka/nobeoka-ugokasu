# みんなの声ポスト（/voice-post/）：公開と運用の手順

福富千恵と延岡を動かす会が、福祉に関する意見・疑問・改善提案を年間を通じて募集する常設ページです。募集期限はありません。

## 現在の接続状況

`src/config/voicePostConfig.ts` に専用フォームを設定済みです。ページの上部と下部に「📮 みんなの声を届ける」ボタンを置き、フォームを新しいタブで開きます。回答項目を変更した場合は、ページに表示している `VOICE_POST_OPTIONS` もフォームと合わせてください。

2026年11月に、ページ内の埋め込み（iframe）を廃止しました。フォームを直接開くと正常なのに、埋め込むと「ファイルが使用できません」と表示される例が報告されたためです。別の環境では再現せず、原因は特定できていません。サイト側では防げない可能性があるため、埋め込みには戻さないでください。

## フォームを差し替える場合

URLが未設定のあいだ、ページは「準備中」の表示になり、入力欄と送信への導線は出ません。検索エンジンにも登録されません（noindex・サイトマップ除外）。回答を受け付けるのは専用フォームだけです。サイトのメニューと `/voices/` からのリンクは、準備中でも表示されます。

1. **福富千恵と延岡を動かす会のGoogleアカウントで**、新しいフォームを作成します。他団体が管理するフォームを流用・コピーしないでください。
2. 設問を次のとおり作成します。
   - チェックボックス（複数選択）：困っていること／疑問に思うこと／こうなったらいいな！
   - 段落（自由記入欄）
   - 氏名・住所・電話番号・メールアドレス・所属施設の設問は作りません
3. 次の設定にします。
   - 「メールアドレスを収集する」：収集しない
   - 「回答を1回に制限する」：オフ（Googleへのログインが必要になるため）
   - ファイルのアップロード設問：使わない（ログインが必要になるため）
   - 「結果の概要を表示する」：オフ（回答者に他の人の回答を見せないため）
   - ページの4つの説明文（`VOICE_POST_NOTICES`）を、フォームの説明文にも記載する
4. 回答用URL（`/edit` で終わらないもの）を `src/config/voicePostConfig.ts` の `VOICE_POST_FORM_URL` に設定します。
5. ビルドして表示を確認します。

既存の申込フォームなどと同じURLは自動で無効になりますが、**サイト外のフォームは自動では判別できません**。設定時に管理者を確認してください。

## 公開前の確認（フォームを差し替えたときも実施）

現在のフォームは、2026年11月に担当者が送信、回答シートへの保存、テスト回答の削除を確認済みです。

- [ ] Googleにログインしていないブラウザ（シークレットウィンドウ）で開き、ログインなしで表示される
- [ ] 複数選択と自由記入で送信でき、回答シートに届く
- [ ] メールアドレスが記録されていない
- [ ] 送信後の画面に「結果の概要」へのリンクが出ない
- [ ] 担当者以外のアカウントで回答シートと編集画面を開けない
- [ ] テスト回答を削除する

## 回答の管理と情報共有

- 回答を確認できるのは、管理権限のある後援会の担当者だけにします。フォームの編集者と回答スプレッドシートの共有相手を担当者に限り、「リンクを知っている全員」での共有はしません。
- 回答はサイトやリポジトリに保存しません。
- 他団体への自動共有（共有設定、自動転送、通知メール、Apps Script、外部連携）を設定しません。
- 公表や関係機関等との共有ができるのは、個人が特定されないよう整理した集計結果だけです。原文は渡しません。
- 少数の回答で個人が推測できる区分は、まとめてから集計します。

## 他の方法で集めた回答との関係

紙など、このフォーム以外で集めた回答は、このフォームや回答シートに入力せず、保管場所も記録先も分けます。
