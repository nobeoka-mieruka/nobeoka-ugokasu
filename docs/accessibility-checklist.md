# アクセシビリティ・表示速度の確認手順

公開サイトの、アクセシビリティ（WCAG 2.2 AA）・スマートフォン対応・表示速度の確認方法です。

## 自動で確認できること（ビルドのたびに実行）

```
npm run build
npm run seo:check     # タイトル・説明文・canonical・OGP・サイトマップ・noindex・構造化データ・内部リンク
npm run check:a11y    # 下の表の項目
```

`check:a11y`（`scripts/a11y-check.mjs`）が確認すること：

| 項目 | WCAG |
|---|---|
| `<html lang="ja">` | 3.1.1 |
| h1 は1ページに1つ（執行部ポータルを除く） | 1.3.1・2.4.6 |
| すべての画像に alt（装飾は `alt=""`） | 1.1.1 |
| `aria-label` は、見えている文字から始める（音声入力で選べるように） | 2.5.3 |
| 背景とのコントラストが不足する文字色（`text-ink-soft/70` 以下）を文字に使わない | 1.4.3 |
| モバイルメニューは `role="dialog"`・`aria-modal`・`aria-labelledby` を持つ | 2.4.3・4.1.2 |
| 名前の無いリンク・ボタンが無い | 4.1.2 |
| ページで使う画像は1枚400KB以下（表示速度） | — |

## ブラウザで確認すること（大きな変更のあと）

自動の検査では確認できないため、パソコンとスマートフォンの実機で確認します。

| 項目 | 確認方法 | WCAG |
|---|---|---|
| キーボードだけで操作できる | Tab・Shift+Tab・Enter で、メニュー・リンク・ボタン・フォームへの移動をすべて行う。フォーカスの枠（濃いオレンジ）が常に見える | 2.1.1・2.4.7 |
| モバイルメニュー | 幅1023px以下でメニューを開き、Tab がメニューの中だけを回ること、Esc で閉じてメニューボタンへ戻ること | 2.4.3 |
| 200〜400%の拡大 | パソコンのブラウザで 200%・400% に拡大し、横スクロールが出ず、文字が切れずに読めること | 1.4.4・1.4.10 |
| 読み上げ | iPhone の VoiceOver・Android の TalkBack で、トップ・意見交換会・みんなの声・お問い合わせを読み上げ、リンクの行き先とボタンの役割が分かること | 1.3.1・4.1.2 |
| 写真・図の上の文字 | トップの見出しなど、背景に模様・グラデーションがある部分の文字が読めること（自動検査では判定できない） | 1.4.3 |
| 動きを減らす設定 | 端末の「視差効果を減らす」「アニメーションを削除」を有効にし、動きが止まること | 2.3.3 |
| 外部フォーム | Google フォーム（意見交換会・みんなの声・入会）は Google 側の画面のため、このサイトでは修正できない。開けることだけ確認する | — |

## 表示速度の確認

Chrome の DevTools → Lighthouse（モバイル）で、トップ・意見交換会・みんなの声を測ります。
Search Console の「ウェブに関する主な指標」で、実際の利用者の LCP・INP・CLS も確認します（データが集まるまで約28日）。
